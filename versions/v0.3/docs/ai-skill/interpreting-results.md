# 结果读取

结果解释至少检查：

- 进程退出状态是否为 `0`；
- 是否出现 NaN、非有限值、collective failure 或 rollback failure；
- 最终连续性、守恒和线性求解诊断是否在配置要求内；
- 输出文件是否对应同一个版本、规范化配置和 rank 布局；
- Restart 是否有完整标记并通过读取检查。

单次运行成功不等于解已经与网格和时间步无关。若要陈述精度或收敛性，必须使用相同物理问题和产品路径进行系统的网格或时间步研究。

壁面力应连同符号定义一起报告。不要混用 operator force、budget reaction 和 surface traction，也不要在后处理时凭直觉再次换号。
