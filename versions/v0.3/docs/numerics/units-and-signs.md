# 单位和符号

配置采用 SI 单位。常用后缀如下：

| 后缀 | 单位 |
| --- | --- |
| `_m` | m |
| `_s` | s |
| `_m_per_s` | m/s |
| `_kg_per_m3` | kg/m³ |
| `_m2_per_s` | m²/s |
| `_pa_s` | Pa·s |
| `_pa` | Pa |
| `_J_per_kg` | J/kg |
| `_J_per_kg_K` | J/(kg·K) |
| `_K` | K |

外边界法向指向计算域外部。浸入表面法向与 `fluid_side` 共同决定，使用 STL 前必须确认三角面封闭、方向一致，并检查流体侧选择。

壁面力诊断区分四个量：离散算子作用于流体的力、预算反力、表面牵引积分，以及两条路径的一致性差。符号转换只在定义好的接口处发生，不能自行对某一分量再次取负。
