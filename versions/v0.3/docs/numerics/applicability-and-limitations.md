# 适用范围与限制

适合当前版本的工作包括：

- 结构化六面体网格上的低马赫数流动；
- 常密度、物质密度和理想气体密度闭合；
- 五类已实现的外边界；
- 通过 schema 3 或公开 C++ 接口运行单个封闭、静止 STL 浸入边界；
- body-fitted 或 static IBM 上的 WALE；
- 固定分区下的 MPI 并行、Restart 和诊断。

九个 schema 3 profiles 已接入 driver、Checkpoint v3 和 diagnostics。当前源码仍是 `0.2.0 candidate`；24/48-cubed formal rows 在 S3-V1 前只算冻结的候选门槛，不是已发布结论。

目前不要用于宣称以下能力：

- 可压缩激波、声学或高马赫数流动；
- 移动或变形浸入边界；
- 多个相交表面、非流形或未封闭 STL；
- rank 数变化后的 Restart；
- 已经验证的生产级 LES、反应流、喷雾、颗粒或 GPU 计算；
- 48³以上规模的性能和强扩展保证；
- 任何 96-cubed 执行（Stage 3 永久排除）；
- 任意扭曲网格或复杂几何上的统一收敛阶保证。

程序通过配置校验并不等于物理设置合理。正式使用前仍需检查网格质量、时间步独立性、质量守恒、边界方向和结果敏感性。
