# 退出状态与错误分类

当前 CLI 使用进程退出状态，不定义细分的稳定数字错误码：

- `0`：命令成功；
- 非 `0`：配置、文件、MPI、内存、数值检查或求解失败。

错误文本按来源分为几类：

- JSON Pointer 开头的配置错误；
- `MPI_` 或 collective 相关的并行错误；
- Restart/Checkpoint 完整性错误；
- 线性求解、残差、守恒或非有限值错误；
- 文件系统和诊断发布错误。

自动化工具应先判断退出状态，再保存完整标准错误。错误句子会随诊断改进而调整，不应把整句英文当成稳定机器接口；可以使用 JSON Pointer、明确的格式版本和结构化诊断字段做分类。
