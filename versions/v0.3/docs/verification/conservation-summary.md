# 守恒验证摘要

已接受路径检查了以下闭环：

- 预测通量经过压力修正后形成唯一最终面通量；
- 连续性、输运更新和诊断读取同一最终通量；
- 浸入壁面压力条件与守恒 Poisson 行使用同一边界权威；
- 算子力、预算反力、表面牵引和一致性差的符号关系经过敏感性检查；
- 时间步失败时，集体回退保持已接受状态不变。

小网格端到端运行中，基础守恒量与残差均为有限值。该结论验证实现闭环，不替代用户针对具体算例的质量平衡、网格独立性和边界通量审计。

constant/material/ideal-gas + IBM + optional WALE 的 fast rows 已覆盖同一闭环。24/48-cubed 的最终数值只在 S3-V1 判定，不从小网格结果外推。
