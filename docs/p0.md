# 热力学压力与机械压力

`flow.thermodynamic_pressure_pa` 选择固定热力学压力 \(p_0\)。
624CF 参考值为 `790216.58 Pa`；入口与静压出口继续按机械压力设置。
当前入口为 CN/BE、`outer_corrected` 与 `boundary_absolute`。
配置、原生 Restart 和化学源身份共同登记该值。

物性查询、随机场、field0 与颗粒气相采样使用同一个 \(p_0/h/Y\)
状态。物性导数仍表示热力学导数，机械压力校正采用零密度导数。
热量与组分更新后的 EOS 密度进入压力投影；最终通量、连续性和
EOS 审核沿用共同门槛。机械压力具有独立的有限数值域。

机械绝对压力为 \(p_m=p_{ref}+\pi\)，机械超压为
\(\Pi=p_m-p_0\)。能量库存采用
\(\rho h-p_0+\rho |U|^2/2\)，面能量通量为
\(\dot m(h+|U|^2/2)+\Pi\dot m/\rho_f\)。
机械压力功和压力投影共用权威质量通量，IBM 入口使用已指定的
流体侧速度与切面面积。统计焓输运、气液交换及黏性功进入同一账本。
诊断项 `mechanical_pressure_work_outflow_W` 单独记录机械超压功。

固定压力检查采用 10 毫米模型域、624CF 原时间步及煤油四步反应／
2 场 ESF／Vreman／动态 TCR／IBM／THICK_EX／SGS 破碎组合。
模型检查的几何尺度与颗粒权重共同缩放，保持气液库存比例。
完整 624CF 几何、边界和源检查点由其独立迁移流程承接。
