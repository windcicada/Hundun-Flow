# V1.1.0 验收范围

本次发布采用模型搭建及必要运行验收范围，实场长期调试接续开展。

| 项目 | 覆盖范围 |
| --- | --- |
| 线性与输运 | 有限迭代递推、独立真实残差、公共面系数与矩阵复用 |
| 并行内核 | 滤波、化学任务、零任务、源项与组成账本的 1／2／4 进程检查 |
| 气相 | JL4、四场 ESF、动态 TCR，新算及 1／2 进程续算 |
| 气液 | 煤油四步反应、THICK_EX、动态 TCR、IBM，共同交换及 1／2／4 进程恢复 |
| 动态模型 | dyn711 的 4／8／16 场历史和跨分区恢复 |
| Restart | 文件校验、原子发布、分配失败和系统调用失败处理 |

原始质量、元素及能量预算与方程残差分别保留。有限迭代流动采用独立
离散方程收支及可追溯浮点误差界核对；解析问题和封闭交换使用各自严格阈值。

示例提供模型使用与续算演示。完整几何实场、长时统计及生产参数专项调试
作为后续开发内容。源代码快照、程序身份、运行包和 SHA-256 校验和共同标识发行版本。
