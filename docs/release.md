# Hundun-Flow V1.1.0

面向固定笛卡尔网格和静态 IBM 的压力基流动、传热、燃烧及稀相喷雾模拟程序。

## 本版内容

- CN/BE 外迭代耦合、有限迭代线性求解与独立真实残差报告。
- 公共 PDF 输运面系数、被动标量已组装入口及预条件复用。
- 化学工作区复用、物理随机场与 field0 分别缓存的物性闭合。
- 质量、元素和能量收支分项，化学交换密度权重修正。
- 动态 TCR 化学不变量处理与中心化滤波。
- 分区 Restart 复读校验、原子提交和阶段计时。

## 使用

Linux x86-64 运行包包含程序、MPI、真实化学后端、依赖许可及小规模续算示例。
解压后使用 `./run --version` 查看版本，`./run check case` 检查示例，
`./mpirun -n 2 ./run run case --restart restart --output next --steps 1` 续算。
源码包包含构建说明、气相和气液示例。`SHA256SUMS` 提供附件校验和。

## 验收与适用范围

本次验收覆盖选定的线性、输运、化学、动态 TCR、气液交换和跨分区恢复路径。
详细范围见附件 `ACCEPTANCE.md`。大规模实场持续调试及长期统计列入后续工作。
动态模型使用显式模型身份和历史时钟；旧方法状态通过原生恢复策略或外部场导入初始化。
当前生产范围为固定笛卡尔网格、静态 IBM 和稀相颗粒。
