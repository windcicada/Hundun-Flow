# 气相分子输运

`thermophysics.d` 在每个组分段指定输运关系。Perry/Wilke 混合物
支持常规气体的对应态关系与煤油蒸气的分段关系：

```text
species H2
...
transport_perry 33.3 12.8
end_species
species C12H23
...
transport_kerosene
end_species
```

`transport_perry` 的两个参数依次为临界温度 K、临界压力 atm。
`transport_kerosene` 对应 C12H23，参数由固定版本的经验关系提供。
这一混合物族中的各组分使用上述两种设置，黏度以摩尔分数进行
Wilke 混合；输入与流动字段保存质量分数，通过组分摩尔质量转换。

煤油蒸气的动力黏度单位为 Pa·s，温度单位为 K：

| 温度分段 | 黏度关系 |
|---|---|
| T ≤ 400 | 1.051939e−6 + 1.325433e−8 T + 1.901751e−27 T⁸ |
| T > 400 | −2.872095e−5 − 1.444046e−8 T + 2.104857e−6 √T |

流动输运与 THICK_EX 气膜查询共享该关系。气膜混合规则仍使用
其独立的表面状态与三分之一温度关系；远场黏度由已接受流动物性
提供。物理计划身份包含煤油关系版本及适用的组分位置。

当前 CN/BE 混合物采用单位 Lewis 数的总焓输运，Pr、分子 Sc 与
湍流 Sc 均为 0.70。物性资产定义温度上下界；分子黏度与导热系数
查询采用有限性和正性检查。

`ker-flow` 验证资产采用 624CF 的七组分热物性和四步反应。
完整 COAST `viscos` 例程提供 110 组 FP64 对照值，覆盖
200–6000 K、400 K 分段附近、七种纯组分与混合组成。该温度
区间为代数实现对照范围，实际模拟依据算例的物理适用条件设置。
输入列与原生标量通过组分名称对应，其中 N2 为余组分。
详细源文件身份和阶段记录见[算例接入记录](rc.md)。
