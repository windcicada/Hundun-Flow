# 所有权与生命周期

运行期对象大致分为四类：

- 配置与网格：初始化后保持不变，由驱动层持有；
- 字段布局：由 `FieldRegistry` 定义，`FieldStorage` 持有实际存储；
- 通信计划：绑定既定分区和字段布局，不能在布局变化后继续复用；
- 时间步状态：区分已接受状态和试算状态，提交或回退由集体协议决定。

公共类型中返回的 view 不拥有内存。其有效期不能超过对应 storage、Halo 或求解对象，也不能在重新分配后继续使用。

诊断 source 同样是借用关系。调用方必须保证被观察对象在收集完成前仍然存在。Restart 读取先在临时对象中校验完整性，全部检查通过后才写入正式状态。
