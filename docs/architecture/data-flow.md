# 数据流

| 阶段 | 权威状态与失败处理 |
| --- | --- |
| 输入编译 | rank 0 读取并类型化 JSON/数据文件，广播有界模型，全 rank 检查状态 |
| 产品构建 | 冻结网格、字段、边界、物性、求解器、通信和 I/O 容量 |
| 初始化 / 恢复 | 显式初场或完整性检查后的 owned image；方法恢复与来源缺历史分开 |
| 时间步尝试 | 从最近接受状态准备预测器、物性、动量与标量输运 |
| 联立校正 | SIMPLE/PISO 更新压力、焓、密度、速度及面通量；有组分时进行配套迭代 |
| 接受或回退 | 检查数值合同并全 rank 汇总；失败不提交中间组成或试算载荷 |
| 输出 | 写 Visit、Restart、Evidence 和统计；输出失败不得改写已接受步状态 |

组成 sweep 与真正 dt retry 是不同循环，不能只用步号证明缓存仍有效。求解成本、重试成本、输出成本和完整墙钟应分开记录。
