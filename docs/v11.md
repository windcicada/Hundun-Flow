## Frozen PDF composition budget derivation

For an independent component, the frozen stage solves
`Rt = rho0*(Yt-Y0)/dt + div(F*Yt) - Yt*div(F) - N - M`.
Chemistry is applied at the same frozen density; its registered mean source is `C`.
The published physical inventory uses final coupling density `rho1` and final mean `Y1`:
`B = (rho1*Y1-rho0*Y0)/dt + div(F*Yt) - N - M - C`.
Thus `B = Rt + Yt*div(F) + (rho1-rho0)*Y1/dt + U`, where `U` is the
unexplained remainder (chemical-source mismatch, tuple roundoff or implementation error).
The transport residual and advective conversion freeze before chemistry from the actual
field, common fluxes and IEM/noise formula; density conversion is accumulated after pressure
coupling. Element rows use the same stoichiometric mapping. Raw `B` and original strict
`admissible` behavior remain unchanged. The additive decomposition is reported separately.
The ledger regression requires source omission/duplication to remain visible in `U`, and
also requires an explained nonzero physical defect to remain outside strict physical
conservation acceptance.

### Centered dynamic filter and pressure-work comparison

Uniform scalar donors with rho=0.3123456789+i*0.0001, V=1e-9 and
Y=0.7123456789 produced L=5.8207660913467407e-11 in the raw second-moment
subtraction. Centering evaluates the same identity as
`L=E[rho*(Y-Ybar)^2]+2*Ybar*E[(rho-rhobar)*(Y-Ybar)]`, in extended
accumulation precision. Uniform scalar L is exactly zero. After this fix,
JL4 cross-partition TCR history relative error is 2.0199952821542411e-12.
The fixed-material kerosene kernel supplies its own invariant-species
certificate because its asset contains thermodynamics and empty kinetics.

The JL4 primary pressure difference is 7.3778210207819939e-9 Pa. Comparison
uses absolute thermodynamic pressure as the pressure scale, rather than a
near-zero gauge origin. Persisted enthalpy spatial rate contains U.grad(p):
its comparison adds the independently computed propagated primary-state
bound `2*max|delta p|*max|U|_1/min(dx)` to the unchanged relative rate target.
This bound uses mesh and pressure/velocity fields, never the measured rate
difference. Operator/cache equivalence tests retain their original threshold.
