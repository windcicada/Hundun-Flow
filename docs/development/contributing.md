# 贡献说明

提交修改前，请先确认职责和文件边界，遵守[源码目录与命名规范](naming-and-style.md)。产品代码只能依赖公开列出的第三方组件，不得加入来源不明的代码或数据。

建议的本地检查顺序：

```sh
cmake -S . -B build/debug -DCMAKE_BUILD_TYPE=Debug
cmake --build build/debug -j 2
```

产品仓库不分发内部测试体系。外部贡献应附上可复核的问题描述、最小输入、预期行为和实际行为；涉及数值方法时，还要说明方程、离散、单位、守恒与收敛影响。

不要在一个提交中混合大范围重命名和算法修改。保持 Apache-2.0 许可证头，第三方材料要单独标明来源与许可证。
