# 贡献说明

提交前核对[当前源码目录与命名规范](naming-and-style.md)，区分正确性修复、观测和算法实验，保留用户未提交的工作。

仓库提供 `versions/v0.4/tests`，使用独立的测试构建和针对性回归。涉及数值方法时说明方程、离散、单位、守恒、精度和方法历史影响；性能变化必须有同方法、同物理窗口的实际证据。不要与占满资源的长测并发执行测试。

保留 Apache-2.0 许可证头与作者水印；第三方材料标注来源与许可证。每次提交使用 `git commit -s` 认证 [DCO](../../DCO.md)。清理旧目录不应顺带修改算法、持久化合同或科学阈值。
