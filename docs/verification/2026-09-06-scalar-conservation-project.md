## 根因与校正设计边界

现有 predictor 给出守恒的 `M* q*`，其中 `M*=rho* V`；最终压力—焓校正改变
密度为 `M`，但没有配对校正标量面通量。最终库存以 `M q*` 计，留下分裂缺口。
必须同时满足以下两个离散方程，而不是只把积分总量调对：

\[
a_0 M_i^{n+1}+a_1M_i^n+a_2M_i^{n-1}+\sum_f\Phi_{if}=0,
\]
\[
a_0(Mq)_i^{n+1}+a_1(Mq)_i^n+a_2(Mq)_i^{n-1}
+\sum_f F_{q,if}=S_{q,i}.
\]

这里的时间层/外推必须与实际 BDF2/EX2 离散一致，不能把所有通量随意替换成
后向欧拉。设计中的 `delta Phi` 是最终质量通量与 predictor 所用等效质量通量
之差，包括它们实际的时间权重，不一定是两个裸数组直接相减。

1. 先冻结 predictor 的库存与等效面通量依据，显式量出每单元及全域缺口。
   被动标量先独立求解最终密度下的局部守恒校正，同时校正面通量；不得只用
   `q <- rho*/rho*q`，因为它会破坏常量保持。
2. 对常量 q0，校正必须满足 `delta F_q=q0*delta Phi`；利用质量校正方程，使
   密度变化项与面通量变化项在每个单元精确配对抵消。每个内部面仅有一个通量，
   两侧单元符号相反，MPI 接口同样如此。
3. 有界性在面校正层实现，不在完成后逐单元裁剪。先证明低阶配套状态可容许，
   再限制反扩散通量；时间历史和隐式扩散的贡献要进入可容许余量，不能套用
   仅适用于显式欧拉的 CFL 证明。
4. 组分不能照搬被动标量的单向后处理。Y 的改变会改变 cp、R、T 和 rho，必须
   与 p/h/EOS 在同一个候选状态中重新闭合；所有组分通量之和等于质量通量，
   组成 simplex、焓温度范围和压力正性共同验收，不做事后组分归一化。
5. 保留现有时间步一致提交/回退；不在已接受状态上修补库存。新方法若改变速率
   或历史解释，更新独立 method/history signature，重启时使用明确方法恢复和
   新统计 epoch，而不是改写源格式标记。
