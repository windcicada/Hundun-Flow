### Pre-registered replicated-coarsest architecture and evidence matrix

The main agent selected the first coarse-communication experiment after
reviewing the public-method receipt
`docs/research/2026-08-22-v04-replicated-coarse-solve-authority.md` and the
current native Cartesian MG implementation.  This is an experiment freeze,
not a candidate freeze or an `ACCEPT` decision.  The implementation must be
independent HUNDUN code and may use only the public mathematical, layout and
lifecycle ideas recorded in that receipt.

The selected route is an internal **replicated coarsest solve**.  It leaves the
public MG interface, restriction, prolongation, Krylov policy, 24 coarse
sweeps, relaxation weight, exact/coarse coefficient construction and the
`C1 -> transport -> PISO1 -> C2 -> PISO2` execution seam unchanged.  Production
activation is automatic only when all of the following frozen conditions hold:

1. the plan communicator has more than one rank;
2. the coarsest level uses the point smoother (`line_axis_mask == 0`);
3. the product of the three global coarsest extents is positive, fits all
   checked allocation/MPI-count bounds and is at most **4096 cells**;
4. one cold rank-order gather of coarsest `(begin, cells)` descriptors proves
   an exact, non-overlapping, no-gap cover of the global coarsest Cartesian
   box.

Failure of any eligibility condition selects the existing distributed route;
it must not produce a partial replicated plan.  There is no public threshold,
rank, communicator or replication control.  A private test seam may force the
reference route or request replication, but must be absent from the
tests-disabled production binary.

Cold setup freezes rank-order counts/displacements, the global lexicographic
index map, each global cell's owner and owner-local parity, and fixed-capacity
RHS, solution, matrix-action and seven-row-coefficient buffers.  The seven
coefficient values are the diagonal followed by the low/high x, y and z face
coefficients used by that owning row.  After the existing coarse coefficient
builder completes, one blocking `MPI_Allgatherv` creates the active replicated
operator.  Numeric refresh first builds the inactive distributed hierarchy,
then gathers an inactive replicated operator; neither distributed nor
replicated numeric state is published unless the complete refresh and the
existing collective consensus succeed.

Each eligible hot coarse solve performs exactly one rank-order blocking
`MPI_Allgatherv` of the current local coarsest RHS.  Every rank unpacks the
same global RHS and starts from the same global zero correction.  For each of
the existing 24 sweeps and two colors, it evaluates the seven-point operator
from a full global solution snapshot and then updates only cells whose
**owner-local** `(i+j+k)&1` equals the selected color, in owner-local
lexicographic arithmetic order.  This snapshot rule reproduces the current
MPI semantics even when adjacent cells on an odd partition boundary have the
same owner-local color.  Periodic wrap, Neumann self value and Dirichlet zero
value follow the existing row semantics; no naive global-parity substitution
is allowed.  Each rank copies its owned global correction back to the existing
coarsest workspace, revises that slot, and then uses the unchanged
prolongation path.  No correction scatter is needed.

The new collective schedule is fixed and blocking.  No rank may return before
a matching planned collective.  An MPI or numeric failure reaches the
existing post-cycle consensus and must not publish a fine correction.  All
maps, communicators and buffers are cold-owned; allocation, map construction
and communicator construction in `apply()` are forbidden.

`MgPlanCounters` and the driver resource snapshot must account for these
direct MG collectives separately from reduction collectives, then include
them in evidence `blocking_collectives`.  The counter advances once for the
cold descriptor gather, once for every attempted operator `Allgatherv`, and
once for every attempted RHS `Allgatherv`.  Logical payload bytes are defined
as the global receive payload delivered to one participating rank: six
32-bit integers per rank for descriptors, seven FP64 values per global cell
for an operator gather, and one FP64 value per global cell for an RHS gather.
Reduction time remains reduction-only; direct-MG collective time must not be
mislabelled as reduction time.

### Frozen architecture and evidence matrix

This is an experiment freeze, not a new candidate freeze or performance
acceptance.  The selected route is an independently designed, cold-owned
**indexed point-row** layout.  It changes neither public MG APIs nor pressure
mathematics, coefficients, point/line smoother policy, sweep counts, halo or
collective schedules, Krylov policy, arithmetic order, convergence tests, or
the `C1 -> transport -> PISO1 -> C2 -> PISO2` seam.

For every MG level, compile derives from the already validated workspace
requirements one signed 32-bit storage offset for the center and each of the
six neighbours of every owner-local cell.  Offsets are relative to the
`FieldView::base` interior origin and stored in owner-local x-fast
lexicographic row order.  The workspace contract already bounds the complete
arena to `INT32_MAX` doubles; compile must additionally checked-convert every
center and neighbour offset and fail transactionally if it cannot.  A
Dirichlet exterior neighbour receives `INT32_MIN` and must never be
dereferenced.  A Neumann exterior neighbour receives the center offset.
Interior, rank-interface and periodic neighbours receive their padded local
or ghost offset.  All four workspace slots of a level share the same strides,
ghost width and allocation-relative layout, so the immutable table is valid
for solution, RHS, residual and temporary views until the existing workspace
binding identity changes.  Numeric coefficient refresh does not rebuild or
modify this symbolic table.

The indexed row evaluator reads the center and six neighbours through those
offsets and applies the existing coefficient arrays in exactly this sequence:
diagonal multiply, then x-low, x-high, y-low, y-high, z-low and z-high
subtractions.  A sentinel contributes exact `0.0` without a field read.
Coefficient indexing and cell traversal remain unchanged.  It replaces
dynamic `Int3`, exterior, boundary-kind and padded-stride resolution only in
the existing full matrix, direct defect and fused point-color actions.  Line
relaxation retains the current generic neighbour path because its transverse
and end-row semantics are a different kernel.  The replicated coarsest route
retains its global indexed operator and is not rewritten.

Cold ownership is one fixed-capacity contiguous `int32_t` table on the MG
plan, with per-level offsets in the immutable level descriptors.  Allocation,
growth, map construction, boundary dispatch and checked conversion in
`apply()`, smoothing or residual construction are forbidden.  Compile and
all existing update failure paths must leave no partially published plan or
numeric hierarchy.  The public symbolic/numeric fingerprints remain the
mathematical identities; tests-on may expose only a private reference switch
and table oracle, both absent from tests-disabled objects and binaries.

## Certified Chebyshev-Jacobi pressure-smoother experiment freeze

The next route is frozen from the retained pre-index source commit `767fbd3`,
not from the governance HEAD containing the rejected indexed-row code.  Public

candidate and does not authorize COAST pairing, full20 or long statistics.

The profile-selected change is an explicit, certified native point-smoother;
it is not an exact-arithmetic rewrite of red/black relaxation.  Add public
`MgPointSmootherKind::{red_black,chebyshev_jacobi}` and

Only `PressureVelocityCoupler::make_native_pressure_mg_spec` selects

`symmetric_diagonally_dominant_m_matrix`.  That producer authority follows
from the already validated pressure construction

```text
d_i = a0 * volume_i * (drho/dp)|h,Y + sum(six nonnegative face coefficients),
a0 > 0, volume_i > 0, (drho/dp)|h,Y > 0.
```

Each pressure face has one current face-coefficient authority, so the two
adjacent rows use the same physical coupling.  Activity masking zeros a
fluid--solid connection on both the exact and MG operators.  The existing
coarse construction restricts a nonnegative non-face diagonal remainder and

diagonal and nonnegative finite faces and that the diagonal is at least the
six-face sum; inactive rows must remain the existing identity rows.  A claimed
certificate that fails is a collective `numerical_failure` and leaves the
active numeric hierarchy, generation, counters and smoother bounds unchanged.
`general` inputs and all line/coarsest levels keep the current smoother and do
not pay a hot applicability branch.  No caller may obtain Chebyshev behavior
without the explicit operator-class certificate.

For a certified row, Gershgorin bounds the spectrum of `D^-1 A` in `[0,2]`.
The frozen upper bound is therefore exactly `beta = 2.0`, with no eigenvalue
estimation and no new collective.  The target high-frequency interval is
`[alpha,beta]`, where `alpha = 0.3 * beta`.  One configured point sweep means
one Chebyshev recurrence stage; hence the current pressure defaults execute a
degree-two pre-polynomial and a separately initialized degree-two
post-polynomial.  With

```text
theta = (beta + alpha) / 2
delta = (beta - alpha) / 2
sigma = theta / delta
rho_0 = 1 / sigma
```

stage zero forms the current exact level defect `r = b - A*x`, sets
`p = (1/theta) D^-1 r`, and updates `x += p`.  For stage `k > 0`, set

```text
rho_k = 1 / (2*sigma - rho_(k-1))
p = rho_k*rho_(k-1)*p + (2*rho_k/delta) D^-1 r
x += p.
```

All constants and recurrence intermediates must be finite.  The implementation
is independently derived from the public polynomial definition; no PETSc or
hypre source, control flow, type, comment or naming layout may be copied.

Chebyshev applies only to non-coarsest levels whose compiled
`line_axis_mask == 0`.  Line-relaxation levels and both replicated and
distributed coarsest solves retain their current algorithms, sweep counts and
arithmetic.  `reverse` has no mathematical role for a polynomial: pre and post
each restart the recurrence from their own current defect, and this explicit
rule replaces traversal reversal only on certified Chebyshev point levels.
Outer FGMRES, exact pressure operator, true-residual interval/tolerances,
null-space handling, restriction/prolongation, replicated-coarsest route and
the `C1 -> transport -> PISO1 -> C2 -> PISO2` seam are unchanged.

The existing four persistent slots are sufficient.  `solution` and `rhs`
retain their meanings, `residual` holds the current exact defect, and
`temporary` holds the recurrence direction.  Each stage performs the fixed
sequence `exchange(solution) -> defect -> recurrence/update`.  A pre-smoother
requesting retained final defect performs exactly one registered final
`exchange(solution) -> defect` after its last update, so restriction consumes
the current defect.  Post-smoothing publishes the updated solution without an
unused final matrix action.  No allocation, estimator, reduction, dynamic
dispatch or policy decision is allowed in hot apply.  The compiled level table
contains the selected function/lifecycle route.

## Collective preconditioner-status follow-up freeze

implementation commit `e188e0c7f309c9cccf54542bde673137e0cef1e5` and the

not a case-specific pressure branch.

`LinearPreconditionerCertificate` gains a closed status-scope value with two
states: `rank_local` is the default and preserves the current mandatory outer
consensus; `collective` certifies that every `apply` invocation executes the
same internal collective schedule on all ranks and returns an already agreed
identical `Status` on every rank before it returns.  The scope is included in
the collective solve-contract fingerprint, and an invalid or rank-mismatched
value rejects the solve before any callback.  Existing third-party or test
preconditioners remain `rank_local` unless they explicitly prove and declare
the stronger contract.

already begins with borrowed-service and field/workspace consensuses, routes
every V-cycle, projection, revision and counter failure through its reduction
engine, and reaches the successful output publication only after the final
counter consensus.  The global projection/nonfinite decisions are identical
on every rank.  Therefore its returned status is collective and its output is
valid on every successful return.  HYPRE remains conservatively
`rank_local` in this experiment even if a future separate audit could prove a
stronger scope.

FGMRES reads the frozen certificate once during solve preparation.  For
`rank_local`, it retains the existing immediate post-preconditioner consensus.
For `collective`, it checks the returned status directly: failure terminates
as `preconditioner_failure` before the pressure operator, while success enters
the same `sigma=1` operator/projection/norm column.  No other consensus,
operator, audit or publication point moves.  PCG and BiCGSTAB behavior is
