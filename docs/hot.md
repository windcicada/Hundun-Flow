# GTMC 展示场

README 图像来自 Hundun-Flow 原生续算的已接受第 32016 步，
物理时刻为 0.021815582522232955 s。本次图像用于展示燃烧场与
软件的原生运行能力；统计采样、性能对照与完整物理组合验收
按 [开发计划](alg.md) 和 [燃烧／喷雾记录](rc.md) 分项推进。

| 项目 | 数据与定义 |
| --- | --- |
| 物理模型 | methane/jl4、4 场 ESF/TPDF、IEM、Vreman、静态 IBM |
| 网格 | 153 × 325 × 151，共 7,508,475 单元 |
| 中央截面 | XY 面，最近实际单元中心 z = −0.075 mm |
| 合速度 | 三个速度分量的欧氏范数，截面范围 0.653510–146.999060 m/s |
| 温度 | 由物理平均焓和组分通过正式 NASA7 物性反演；截面范围 290.981794–2242.747742 K |
| ESF 状态 | 物理平均焓／组分用于温度；独立 field0 用于压力耦合密度 |
| 三维采样 | 每轴每隔一个单元取实际中心值，保留真实坐标；二维截面采用全部原始单元 |
| 三维构图 | 完整半透明 STL 几何与 1400／1800 K 温度等值面 |
| 流线 | 五个高度的实际流体单元内布置 435 个种子点，双向积分形成 606 条轨线，以合速度着色 |
| 色标 | 速度 0–150 m/s；温度 290–2300 K；CMC batlow／lajolla |

读取过程逐份核对全部 128 份原生 Restart 的长度、文件校验值、
尾部校验值和公共元数据，并核对运行 Evidence 中的步号、时刻及
程序身份。截面与三维采样覆盖均为每个目标位置恰好一次。
温度恢复使用正式输入编译后的分段焓连续化系数；2,068 个覆盖
全域分区的流体样本与正式 `ThermodynamicsPlan` 查询相比，最大
温度差为 9.094947017729282e-13 K。

PNG 用于网页展示，PDF／SVG 提供同版式输出；三维场以渲染图
嵌入 PDF／SVG，文字和色标由绘图工具排版。可编辑绘图入口为
[gtmc_fig.py](../tools/gtmc_fig.py)，依赖 numpy、matplotlib、pyvista
及 cmcrameri。输入为核验后的采样场 NPZ 和实际 SI STL：

```sh
python tools/gtmc_fig.py --data field.npz --geometry gtmc13_si.stl --output fig
```

本地提取、正式物性核对及图面审核记录位于 `check/js`；原生场
保持在 `check/jk/run/Restart`。图像来源及资产哈希见
[hot.json](hot.json)。
