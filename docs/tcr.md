# 动态 TCR 生产模型

624CF 对应模型身份为 `cdphyso_dynamic_v1`，运行模式为 `experimental` 或
`shadow`。两种模式均计算和保存动态历史；`experimental` 将已接受的
逐组分 κ 和动态 Cd 用于下一步隐式 IEM，`shadow` 使用基础 IEM 系数。

```json
"tcr": {
  "model": "cdphyso_dynamic_v1",
  "mode": "experimental",
  "fuel": "CH4",
  "weak_rate_threshold": 1e-12
}
```

GTMC 使用 `CH4`、JL4、4 场 ESF，基础 `c_z=1` 对应 Cd=2。
624CF 使用 `C12H23`、煤油四步反应、2 场 ESF，基础 `c_z=0.25`
对应 Cd=8。两例采用 Vreman。动态更新后的 Cd 由空间统计确定。

本模型采用 624CF 已冻结 `compute_tcr_kappa.F90` 的 CD-PhySO
逐组分代数控制、`statistics.F90` 的双重空间滤波与分组 Cd，
`mixer.F90` 的 `cbrt(κ)` 混合控制。参考身份见 [续算记录](rc.md)
S6。原始 `src.TCR.dyn711` 的八步率累计和时间尺度分支选择具有独立
的方法定义；当前模型身份明确对应逐步 CD-PhySO 版本。

每步先完成 ESF 输运和隐式混合，再计算随机场化学区间与 field0
参考化学区间。两套组成增量按相同分子量和时间转换为比摩尔反应率，
以 η=0.3 计算直接根、η 投影或弱反应补全。field0 采用已建立的正权
热力学查询，并承接随机场平均化学增量。κ 范围为 `[1e-4,1]`。
弱反应补全使用流体邻居的同组分有效控制量及全域有效均值。

动态 Cd 在第一个时间区间及随后每四步更新。局部滤波使用 8 个流体
供体、体积和密度权重，第二次滤波使用参考中的局部缩放乘积；
周期面和 MPI 接口按全局格号交换。物理边界采用朝内供体，IBM 梯度
采用可见流体侧差分。标量及梯度统一以质量分数表示。
2026-09-17 用户确认动态滤波统一采用质量分数坐标。完整原始 dyn711
及 624CF 例程对照表明，原式的局部梯度平方已乘分子量平方，而滤波
梯度平方仍使用比摩尔数坐标。67 组非单位分子量模板中，dyn711 的
489／536 个最终 C_phi、624CF 的 1584／1608 个分组系数发生变化；
最大绝对差异分别为 5.10572 和 4.46126。这些数据度量两种表达式
的差别，实场影响由各模型运行验收评估。[对照数据](gas-tcr.json)

原始 Cd 范围为 `[1,16]`，分组混合系数范围为 `[1,10]`；H2O/CO2
及焓使用产物组，O2/燃料使用反应物组，其余组分使用自由基组。
所选机理中的 OH 组缺省值沿用基础 Cd。

当前统计使用输运／化学候选场及本步冻结载体密度，在压力外迭代前
完成。已接受的历史为全部候选重算提供统一系数；新历史随流场和
颗粒一起提交或回退。每格记录包含接受步号、更新相位、组分数、
PDF/PSR 区间反应率、κ、离散状态和三个 Cd。喷雾组合按模型统一
选择记录版本，原生 Restart 保存上述完整状态。

必要检查覆盖代数与历史事务、输入广播、真实煤油 ESF/IBM/THICK_EX/
SGS 破碎组合及 1/2/4 进程恢复。详细数据见
[组合运行证据](rc-tcr-run.json.gz)。GTMC JL4 的模型入口位于
`versions/v0.4/tests/fixtures/jl4-flow`，采用相同动态模型与正式化学后端。
该入口使用质量流量入口、静压出口及 GTMC 原时间步
`6.5569904281136158e-7 s`，完成 1/2 进程新算／恢复。
[JL4 运行证据](rc-jl4-tcr.json.gz) 按流场相同的 `1e-11` 归一化标准
比较浮点历史，记录头、离散状态与颗粒数据保持逐字节对照。
整场迁移、长期统计及原生根输运 DAE 的研究验收按各自范围接续开展。

固定压力组合中的活跃区间率按 FP64 相减误差传播检查 κ，
具体区间、原始差异及字段门槛见 [S29](rc.md#s29-固定热力学压力与模型收尾)。
该检查保持逐格选根关系、离散状态和率／Cd 的原比较标准。


## dyn711 原生模型

`dyn711_v1` 使用 CN/BE、`outer_corrected`、真实化学后端和 Vreman。
`experimental` 应用已接受的 κ／Cφ；`shadow` 保存模型历史并采用
基础 IEM 系数。输入指定燃料、混合分数被动标量及氧化剂氧质量分数：

```json
"tcr": {
  "model": "dyn711_v1",
  "mode": "experimental",
  "fuel": "CH4",
  "weak_rate_threshold": 1e-30,
  "mixture_fraction": "Z",
  "oxidizer_oxygen_mass_fraction": 0.232
}
```

`transported_scalars` 中的 `Z` 使用 `passive_scalar`，入口和回流同时
给出其状态。采用 Bilger 元素坐标
`beta=sum((2*C+H/2-O)*Y/W)`，
`Z=(beta+2*Y_O2,ox/W_O2)/(beta_fuel+2*Y_O2,ox/W_O2)`。
终态物理组成提供元素重建初值，公共被动标量 CN/VLS 方程完成本步
输运；已接受历史保持本步起点。此归一化的燃料参考为指定纯燃料，
氧化剂参考由输入指定。源 GTMC 的 Z 归一化按源输入单独登记；整体
常数缩放在动态滤波的乘积比中相消。

每步执行输运、隐式混合及一个化学区间。PDF 和 PSR 的比摩尔反应率
统一采用 kmol/(kg·s)。PSR 初态使用输运后的物理随机场平均组成与焓，
以 PH 约束推进相同 dt。源版采用 field0 焓；本实现使用共同守恒账本
定义的物理平均焓。η 取本步起点全部随机场平均比摩尔数中活跃物种的
比例，N2、H2O 和 CO2 归入稳定物种。

热释放判据沿源版采用 PDF／PSR 乘积和比值，阈值为
`1/(4*eta*(1-eta))+0.3`。触发重新混合时，各随机场使用单次 PSR
区间终态组成和共同焓；field0 承接实际物理平均化学增量。质量、元素、
能量及 PDF 统计使用同一已选择的区间增量。焓的混合控制使用燃料 κ。

最终压力校正和 Z 输运完成后计算动态统计。物种滤波统一使用已批准
的质量分数坐标，物理均值与 field0 梯度按双状态分工提供。Cφ 在调用
1、2、9、16……更新；反应率累计八次，第九次根据已接受窗口选根。
全体候选重算使用同一已接受历史，统计历史参与流场共同提交和回退。

局部 SGS 时间为 `tau_I=rho*k/epsilon`、`tau_K=sqrt(mu/epsilon)`、
`tau_flow=sqrt(tau_I*tau_K)`；epsilon 为体积耗散率 W/m³。
2026-09-17 用户批准方程分辨率一致的局部极限：当 FP64 中
`mu+rho*nu_t == mu` 时，TCR 时间计算使用 k=0，SGS 原始状态继续由
Vreman 提供。正耗散对应零积分／流动时间，零耗散对应无限时间。
该规则登记为 `resolved-sgs-k-limit-v1`，随方法身份进入原生 Restart。

化学时间沿用源规则：消耗组分用 `n/abs(rate)`，生成组分用
`0.5*global_max(n)/rate`，弱反应用 `min(1,global_max(valid_time))`；
全域极值初值为 1e-12，全域弱反应对应 1e-12 s。

原生定向入口为 `v04_dyn711_4_cli`、`v04_dyn711_8_cli`、
`v04_dyn711_16_cli` 和 `v04_dyn711_remix_cli`。运行证据与适用范围
见 [专项工作记录](gas-work.md)，完整 gas.md 专项继续按阶段推进。
