## 初始化投影修正

当前 main 在原圆柱网格的初始化投影中，于 FGMRES 第 60 次迭代
返回 breakdown。运行探针测得，多重网格原始校正 z 满足
`r·Az = -2.2186383408633048e-4`，`||Az||² = 9.6985805939732401`。
原缩放分支将该校正置零，Krylov 迭代随即失去搜索方向。

修正后的残差最小化采用带符号标量
`alpha = (r·Az) / ||Az||²`，保留有限反向校正的有效方向。
原有分母门槛、有限值检查、精确残差和物理审计继续生效。
`solver_mg_chebyshev_test.cpp` 中的最小回归算例构造负内积，
以独立周期七点算子检验校正后的实际残差下降。
