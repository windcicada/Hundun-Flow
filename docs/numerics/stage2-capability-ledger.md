# Stage 2 capability ledger

This ledger is an evidence-navigation index for capabilities accepted through
Task 25. It does not predict the Task 26 or final Stage 2 verdict; those depend
on fresh exact-HEAD commands and reconciliation by the coordinator.

Every capability row has one disposition and follows the same forward and
reverse chain:

`approved requirement -> implementation location -> positive test -> failure/rollback test -> MPI/numerical acceptance`
