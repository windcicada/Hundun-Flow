# 守恒性

共享面质量通量由唯一权威来源发布，相邻控制体以相反方向使用。最终压力—焓状态及通量满足所配置的 EOS、连续性、能量、闭域质量与压力规约要求。

标量预测库存与最终密度通过配对 remap 和组成迭代保持一致，IBM 不可穿透标量切面使用零扩散通量。接受前不提交中间组成；失败必须保留完整已接受载荷。

`mass_pairing_residual` 和最终动量残差的记录不意味着各自存在独立接受门槛。前者的上游约束、后者的归一化及最差单元/分区诊断见[模块验收](../verification/2026-09-07-exclusive-module-acceptance.md)。不得把没有单独门槛写成已经复现的守恒错误。

库存守恒、常量保持、有界性、组成/EOS 一致性与空间/时间精度必须分别检验，不能相互替代。
