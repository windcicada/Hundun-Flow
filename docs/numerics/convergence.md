# 收敛性

空间、时间和统计收敛是不同问题。应对同一物理问题及同一离散方法比较系统细化后的误差，不能从单网格正常运行推断阶数。

本轮 IBM 标量制造解使用 24/48/96 网格。平壁 L2 观测阶约 1.97/1.99；斜壁约 0.86/1.13，圆柱约 1.65/0.86。只有平壁二阶得到该测试支持，曲面几何误差仍参与结果。数据及线性残差、通量检查见[实际验收记录](../verification/2026-09-07-exclusive-module-acceptance.md)。

这组结果不等于压力、速度或 LES 统计的通用精度结论。长期湍流比较应检查守恒与统计量，不把长期逐点完全一致作为唯一标准。
