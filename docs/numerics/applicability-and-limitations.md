# 适用范围与限制

适合当前版本的工作包括：

- 结构化六面体网格上的低马赫数流动；
- 常密度、物质密度和理想气体密度闭合；
- 五类已实现的外边界；
- 通过公开 C++ 接口构造单个封闭、静止 STL 的浸入边界数值核心；
- 固定分区下的 MPI 并行、Restart 和诊断。

0.1.0 的 `hundun` 命令行入口只运行 schema 1/2。schema 3 可以由配置库解析和校验，但尚未接入完整的 IBM driver、Checkpoint 和 diagnostics，因此不能把通过 schema 3 校验当作可运行能力。

目前不要用于宣称以下能力：

- 可压缩激波、声学或高马赫数流动；
- 移动或变形浸入边界；
- 多个相交表面、非流形或未封闭 STL；
- rank 数变化后的 Restart；
- 已经验证的生产级 LES、反应流、喷雾、颗粒或 GPU 计算；
- 48³、96³以上规模的性能和强扩展保证；
- 任意扭曲网格或复杂几何上的统一收敛阶保证。

程序通过配置校验并不等于物理设置合理。正式使用前仍需检查网格质量、时间步独立性、质量守恒、边界方向和结果敏感性。
