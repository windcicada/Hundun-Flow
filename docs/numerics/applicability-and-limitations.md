# 适用范围与限制

当前适用范围以[产品能力](../releases/current-capabilities.md)为准：单相低马赫理想气体、笛卡尔网格、静止封闭 STL IBM、WALE/Vreman、MPI、SIMPLE/PISO 和 BDF 时间推进。

当前冻结 Re3900 计算域是 20D×10D×(π/2)D，网格为 456×256×52，D=0.02 m，Uc=2.89668 m/s。10% blockage、薄展向域和网格分辨率均是解释统计时必须声明的限制，不是实验几何的严格复现。

长测尚在推进，不能把旧域/旧方法下的耗时、统计窗口或压力精度结论直接用于当前程序。单步残差合格不等于网格、时间步、展向域和统计窗口已收敛。

曲面标量扩散二阶精度未通过通用验收；平壁、斜壁、圆柱的实际结果分别记录在[模块报告](../verification/2026-09-07-exclusive-module-acceptance.md)。不因追求阶数而撤销守恒修复。

反应流、喷雾、移动/相交/非流形 IBM、AMR、GPU、高马赫数和声学均不属于当前生产能力。不得在未验证的复杂几何上直接作工程精度承诺。
