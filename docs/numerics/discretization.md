# 离散方法

采用单元中心有限体积离散，共享面按同一权威质量通量、相反法向进入相邻控制体。压力—焓闭环联合约束最终压力、密度、温度、速度与面通量；SIMPLE/PISO 是可选耦合路径，不能把所有配置描述成固定两次 PISO。

时间推进包括固定/变步长 BDF2、启动或恢复时的 BE 及失败重试。实际对流限制与接受状态关联；非对流自动尺度尚未完整接入，不能声称所有扩散或声学 CFL 已自动估计。

有输运标量时，预测库存与最终密度通过配对质量 remap 和组成迭代协调；禁止以密度比例缩放或全局归一化代替守恒校正。组成 sweep 不等于 dt retry。

IBM 重构与标量切面零扩散通量各有适用合同。二值控制体的严格零通量不自动证明曲面二阶精度。具体已测误差、网格收敛和限制见[验收报告](../verification/2026-09-07-exclusive-module-acceptance.md)，方法历史含义见[签名合同](../verification/v04-method-history-contract.md)。

组分携焓对流和扩散在 8×8×8 小块内复用共享面值，每次算子调用使用独立的
栈上缓存。各单元仍按原 x/y/z 面顺序累加；分块边界和固体屏蔽使相应缓存失效，
IBM 切面修正随后使用原面公式执行。该复用保持面重建、容差及方法历史签名。
