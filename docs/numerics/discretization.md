# 离散方法

空间离散采用单元中心有限体积法。面通量在共享面上只保存一份权威值，邻接单元以相反方向使用同一通量，从代数结构上保持局部守恒。

压力与速度通过 PISO 类压力修正耦合。当前浸入流动路径每个时间步执行两次 pressure corrector；最终动量残差、连续性、面通量和壁面力都读取修正后的权威状态。

时间推进支持固定步长和带重试的自适应 BDF2。自适应控制会根据 CFL、扩散数和失败原因调整候选步长；失败试算不会污染已经接受的状态。

静止浸入边界采用 Local Flow Pattern/Ghost-Cell 重构。stencil 在全局分区语义下确定 donor，二次重构同时服务于压力边界、速度梯度和表面量。`kMaximumReach` 一类实现上限约束 stencil 构造，不代表 donor 必须位于本 rank 的局部 Halo。
