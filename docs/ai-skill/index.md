# 外部自动化操作指南

本节供外部 AI、作业调度器或自动化脚本调用 HUNDUN-FLOW。它只描述公开产品接口，不要求工具了解源码开发流程。

按下面的顺序操作：

1. 记录源码版本、编译器和 MPI；
2. 在独立目录构建；
3. 生成或修改 `case.json`；
4. 依次运行 `--validate` 和 `--print-resolved`；
5. 用明确的 rank 数启动；
6. 监控退出状态、标准错误和 diagnostics；
7. 只从完整 Checkpoint 恢复；
8. 保存规范化配置和输出指纹。

自动化工具不得猜测单位、静默修改科学阈值、把单网格结果写成收敛结论，也不得停止不属于当前计算的进程。
