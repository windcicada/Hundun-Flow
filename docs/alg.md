## 公共约定

- 时间格式为 `cn_be`（默认）和 `backward_euler`。耦合标识明确区分
  `outer_corrected`、PISO、SIMPLE，各调度共享方程和数值内核。
- 局部 CFL 默认 `0.30 ± 0.05`；GTMC 固定 dt 性能比较沿用原值
  `9.7088612375381536e-8 s`。圆柱固定 dt 比较沿用已登记检查点的值。
- 公共方程收敛设置继承参考尺度和现有阈值，报告线性残差、原方程残差、
  外迭代和全域收支。原生方法身份和 Restart 记录实际执行的组合。
- 源项携带单位、时间区间和修订号，采用现有贡献注册与提交事务。
  物理增量在最终接受时计入一次；候选重算从同一已接受状态出发。
- SGS、随机场数、TCR 模型身份和破碎模型显式配置，TCR 运行状态与
  验收证据分别记录。
- `hundun import <coast-case> --output <case> [--restart <restart>]`
  承担一次转换。转换后使用 Hundun 原生输入、运行和 Restart。

## 算法与精度约束

- 先通过实际生产接口的最小失败用例，再修正并复验。三组分面模板的原问题：
  `(0,.6,.4), (.2,.7,.1), (.5,.5,0)` 的独立重构形成负余组分。
  公共面处理包含全部组分和热变量，并覆盖周期、MPI 和 IBM 模板。

## 验收标准

| 类别 | 门槛 |
|---|---|
| 算子 | 同输入的系数、RHS、通量和真实残差；FP64 等价算子归一化差异 <= 1e-11；COAST REAL 精度和常数差异单列 |
| 精度 | 平滑空间阶 >= 1.8；独立 CN 动量时间阶 >= 1.8；整体 CN/BE 时间阶 >= 0.9；IBM 近壁和力的网格收敛 |
| 守恒 | 继承各已有算例更严格的阈值；新综合算例归一化质量/元素/能量缺陷 <= 1e-6；EOS、组成及固体状态检查 |
| 冷态效率 | 同网格/场/dt/硬件/核数/物理/输出；10 步预热、100 步计时；各代表算例 <= 有效 COAST 基线的 1.05 倍，同时守住 Hundun 现有基线 |
| 长期冷态 | 相同 CFL、相同物理终点总耗时；Re3900 稳态后至少 20 个脱涡周期，继续采样至统计置信区间具有判别能力 |
| 燃烧 | 真实零维反应器、点火和平面火焰；点火延迟目标 1%，火焰速度目标 2% |
| 随机/喷雾 | ESF/TCR 均值/方差/根约束/分支；阻力、蒸发、破碎概率/粒径分布、颗粒权重与气液账本 |
