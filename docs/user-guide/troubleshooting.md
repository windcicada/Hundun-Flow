# 故障排查

先保存输入、程序及构建身份、运行元数据、标准输出/错误和最后完整 checkpoint。不要覆盖故障现场。

| 问题 | 首先检查 |
| --- | --- |
| 输入拒绝 | 使用 `hundun validate <case-dir> --dry-plan`，核对当前 schema、字段、单位及六面边界 |
| MPI 启动失败 | 运行器与编译使用同一 MPI，核数与局部网格约束可行，没有并发超额作业 |
| 重启拒绝 | `current`、generation、全部载荷和附件完整；区分方法签名、存储迁移与物理计划不一致 |
| 初始化拒绝 | 显式初场与 restart 互斥；多个边界提示冲突时显式指定 `--initial-state` |
| 数值终止 | 对照 failed stage、attempt、dt、真实残差及物理残差；不能仅凭退出码认定 OOM |
| 输出终止 | 区分已提交步与输出失败，检查路径、权限、空间和 rank 一致退出 |
| 性能观测不完整 | 检查全部预期 rank/loop/步，截断日志只作 partial 诊断 |

未知历史不得默认绕过。参见[方法恢复](restart.md)。不得通过放宽残差门槛或静默更换网格、物性和 dt 掩盖问题。
