# 故障排查

## 配置无法通过

先运行 `hundun case.json --validate`。错误消息通常带 JSON Pointer，例如 `/mesh/cells`。按该路径检查 key、类型、单位和组合约束。解析器拒绝未知字段，拼写错误不会被静默忽略。

## MPI 启动后立即失败

确认 `mpiexec` 与构建时检测到的 MPI 来自同一套安装，并核对 `resources.expected_ranks`、`resources.process_grid` 与实际 rank 数。

## Restart 无法读取

检查目录是否含完成标记、manifest 和全部 rank 文件。当前读取要求相同分区；改变 rank 数、网格、边界或持久化字段 schema 都会被拒绝。

## 输出目录已存在或文件不完整

不要让两个计算写入同一目录。保留故障现场后，改用新的输出路径重新运行。程序不会覆盖某些已经发布的事务目录。

## 出现 NaN、守恒明显失控或线性求解失败

停止把该结果用于物理解读，保存规范化配置、标准输出、标准错误、诊断文件、程序版本、编译器和 MPI 信息。先缩小时间步并核对物性、边界方向和单位；不要通过放宽残差标准掩盖问题。
