# 后续分支计划

`client` 持续维护独立工作台、AI 与求解器命令／文件适配。`main` 维护数值求解器。两者通过版本化外部接口协作。

1. 在真实模型服务上积累 GTMC、蒸发与通用冷态工作流使用记录，完善物理定义提问及任务预算。
2. 增加调度器适配、凭据库交互、多用户角色和远端资源查询。
3. 扩展交互三维显示、外部几何／网格工具向导与结果选择归档。
4. 保持任务接口与模型 SDK 隔离，后续评估 RustX 运行时适配，同一操作层继续供网页和 Agent 使用。
5. Windows／Linux 客户端以 CI 维护安装和页面兼容，桌面外壳在稳定 Web 接口上接入。
